05 / ENGINE BOUNDARIES

What this report proves—and what it does not

Recorded by the report

Static parsing, file and project inventory, dependency-manifest observations, local reference checks and any explicitly requested npm audit counts.

Not established by static analysis

Runtime health, exploitability, legal license compliance, deployment readiness, or the absence of defects. Framework route graphs and TypeScript/JSX need native toolchains.

Repair policy

Repairs are separate transactions. Each plan needs operator authorization and approval, expected file hashes, external backups and rollback checks. Findings alone never authorize edits.
