# Portfolio assets

This directory is the canonical home for new portfolio media and downloadable visual assets.

## Structure

- `img/` — profile photography, project screenshots, icons and social-preview images.
- `downloads/` — downloadable portfolio resources where appropriate.

Existing root-level image files and `resume.pdf` are intentionally left in place for now because the current HTML pages reference those exact paths. They can be migrated in a separate verified change without breaking existing links.
